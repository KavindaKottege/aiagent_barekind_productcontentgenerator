    - 'use client' directive

    - Import DebugLogEntry type from '@/app/actions/debug'

    - Define DebugContextType interface:
      - isDebugEnabled: boolean
      - setDebugEnabled: (enabled: boolean) => void
      - debugLogs: DebugLogEntry[]
      - addLogs: (newLogs: DebugLogEntry[]) => void
      - clearLogs: () => void
      - activeJobId: string | null
      - setActiveJobId: (jobId: string | null) => void
      - isAdmin: boolean

    - Create DebugContext with default values (isDebugEnabled: false, empty functions, etc.)
    - STORAGE_KEY = 'debugModeEnabled'
    - MAX_LOGS = 500 (cap to prevent memory issues)

    - DebugProvider component props: { children: React.ReactNode, isAdmin: boolean }
      - State: isDebugEnabled (boolean, default false), debugLogs (DebugLogEntry[], default []), activeJobId (string | null, default null)
      - useEffect on mount (isAdmin-gated): read sessionStorage STORAGE_KEY, set isDebugEnabled if 'true'
      - setDebugEnabled callback: update state + sessionStorage. If disabling, also clear debugLogs.
      - addLogs callback: append new logs to state, cap at MAX_LOGS (keep most recent). Use functional update: `prev => [...prev, ...newLogs].slice(-MAX_LOGS)`. Deduplicate by id: only add logs whose id is not already in the set.
      - clearLogs callback: set debugLogs to []
      - setActiveJobId callback: update activeJobId state
      - If NOT isAdmin, render children without provider wrapper (no debug capability)
      - If isAdmin, wrap children in DebugContext.Provider

    - Export useDebug() hook:
      - const context = useContext(DebugContext)
      - Return context (do NOT throw if undefined -- non-admin pages won't have provider)

    **frontend/src/components/providers.tsx:**
    - Keep existing ClientProvider import
    - Add DebugProvider import from '@/lib/debug-context'
    - Update Providers component signature to accept `isAdmin: boolean` prop (default false)
    - Wrap children: ClientProvider > DebugProvider (pass isAdmin)
    - Result: `<ClientProvider><DebugProvider isAdmin={isAdmin}>{children}</DebugProvider></ClientProvider>`

    IMPORTANT: The Providers component is rendered in the ROOT layout (app/layout.tsx), but the root layout is a Server Component and does NOT have access to user data (that's behind the dashboard layout's verifySession). Since we cannot easily get isAdmin in the root layout without auth (non-dashboard pages like /login shouldn't need auth), we have two options:
    - Option A: Pass isAdmin=false at root level and override inside dashboard layout with a nested DebugProvider
    - Option B: Keep Providers.tsx backward-compatible (default isAdmin=false), and add DebugProvider separately inside the dashboard layout

    Use Option B: Do NOT change Providers.tsx signature. Instead, add DebugProvider directly inside the dashboard layout (which already has user context). This avoids auth calls on unauthenticated pages.

    So actually: Leave providers.tsx UNCHANGED. The DebugProvider will be added in dashboard/layout.tsx in Task 2.

    **frontend/src/components/debug-panel.tsx:**
    - 'use client' directive
    - Import useDebug from '@/lib/debug-context'
    - Import useState, useEffect, useRef, useCallback from 'react'
    - Import { Bug, ChevronDown, ChevronUp, Trash2, X } from 'lucide-react'
    - Import { Button } from '@/components/ui/button'
    - Import { Badge } from '@/components/ui/badge'
    - Import { getDebugToken, type DebugLogEntry } from '@/app/actions/debug'

    - Helper function parsePromptUsed(promptUsed: string): { system: string; user: string }
      - Use regex to extract [system] and [user] sections:
        ```
        const systemMatch = promptUsed.match(/\[system\]\s*([\s\S]*?)(?=\[(?:human|user)\]|$)/)
        const userMatch = promptUsed.match(/\[(?:human|user)\]\s*([\s\S]*)$/)
        ```
      - Return { system: match[1]?.trim() || '', user: match[1]?.trim() || '' }

    - DebugPanel component (no props):
      - Get { isDebugEnabled, debugLogs, addLogs, clearLogs, activeJobId } from useDebug()
      - State: isExpanded (boolean, default true), selectedLogId (string | null), accessToken (string | null)
      - Ref: scrollRef for auto-scroll to bottom, lastTimestamp ref (string) for incremental polling

      - useEffect to get access token on mount: call getDebugToken(), store in state

      - useEffect for polling (depends on isDebugEnabled, activeJobId, accessToken):
        - If !isDebugEnabled or !activeJobId or !accessToken, return
        - Set up interval polling every 2000ms:
          - Build URL: `${process.env.NEXT_PUBLIC_API_URL || 'http://localhost:8000'}/api/debug/logs/${activeJobId}`
          - Append `?since=${lastTimestamp.current}` if lastTimestamp exists
          - Append `&limit=50` (or `?limit=50` if no since)
          - Fetch with Authorization: Bearer ${accessToken}, no-store cache
          - If response ok, parse JSON as DebugLogEntry[]
          - If entries.length > 0: call addLogs(entries), update lastTimestamp.current to last entry's created_at
        - Cleanup: clear interval on unmount/deps change
        - IMPORTANT: Also reset lastTimestamp.current when activeJobId changes

      - useEffect for auto-scroll: when debugLogs length changes and isExpanded, scroll scrollRef to bottom

      - If !isDebugEnabled, return null

      - Render structure (dark terminal-style theme):
        ```
        <div className="fixed bottom-0 left-0 right-0 z-50 border-t-2 border-orange-500/50 bg-gray-900 text-gray-100 shadow-2xl">
          {/* Header bar */}
          <div className="flex items-center justify-between px-4 py-2 bg-gray-800/90 backdrop-blur cursor-pointer select-none" onClick toggle expand>
            <div className="flex items-center gap-2">
              <Bug className="h-4 w-4 text-orange-400" />
              <span className="text-sm font-mono font-semibold text-orange-300">Debug Mode</span>
              <Badge variant="outline" className="text-xs border-gray-600 text-gray-400">{debugLogs.length} entries</Badge>
              {activeJobId && <Badge className="text-xs bg-green-900 text-green-300 animate-pulse">Polling</Badge>}
            </div>
            <div className="flex items-center gap-1">
              <Button size="sm" variant="ghost" className="h-6 text-gray-400 hover:text-white" onClick={(e) => { e.stopPropagation(); clearLogs(); }}>
                <Trash2 className="h-3 w-3 mr-1" /> Clear
              </Button>
              {isExpanded ? <ChevronDown className="h-4 w-4 text-gray-400" /> : <ChevronUp className="h-4 w-4 text-gray-400" />}
            </div>
          </div>

          {/* Expandable log content */}
          {isExpanded && (
            <div className="flex h-72">
              {/* Left: Log list */}
              <div ref={scrollRef} className="w-1/3 border-r border-gray-700 overflow-y-auto">
                {debugLogs.length === 0 ? (
                  <div className="flex items-center justify-center h-full text-gray-500 text-sm">
                    No debug logs yet. Start a generation to see prompts.
                  </div>
                ) : (
                  debugLogs.map(log => (
                    <div key={log.id}
                         className={`px-3 py-2 border-b border-gray-800 cursor-pointer hover:bg-gray-800/50 text-xs ${selectedLogId === log.id ? 'bg-gray-800 border-l-2 border-l-orange-400' : ''}`}
                         onClick={() => setSelectedLogId(log.id)}>
                      <div className="flex items-center justify-between">
                        <span className={log.success ? 'text-green-400' : 'text-red-400'}>
                          {log.success ? 'OK' : 'FAIL'} #{log.attempt_number}
                        </span>
                        <span className="text-gray-500">{log.duration_ms}ms</span>
                      </div>
                      <div className="text-gray-400 truncate mt-0.5">{log.model_version} | temp={log.temperature} | ${log.cost}</div>
                      <div className="text-gray-500 truncate mt-0.5">Tokens: {log.input_tokens} in / {log.output_tokens} out</div>
                    </div>
                  ))
                )}
              </div>

              {/* Right: Selected log detail */}
              <div className="flex-1 overflow-y-auto p-4">
                {selectedLogId ? (render selected log detail -- see below) : (
                  <div className="flex items-center justify-center h-full text-gray-500 text-sm">
                    Select a log entry to view prompt details
                  </div>
                )}
              </div>
            </div>
          )}
        </div>
        ```

      - For selected log detail rendering:
        - Find log from debugLogs by selectedLogId
        - Parse prompt with parsePromptUsed(log.prompt_used)
        - Show header: "Attempt #{log.attempt_number} - {log.success ? 'Success' : 'Failed'}"
        - Show model params row: Model: {log.model_version} | Temperature: {log.temperature} | Cost: ${log.cost} | Duration: {log.duration_ms}ms
        - Show token counts: Input: {log.input_tokens} | Output: {log.output_tokens}

        - If generated_title/generated_description: show output section
