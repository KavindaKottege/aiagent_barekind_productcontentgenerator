<objective>
Create the backend debug API endpoint and frontend server action for fetching generation audit logs.

Purpose: Provide the data layer that the debug panel will consume. The GenerationAudit model already stores prompt_used, model_version, temperature, tokens, cost, and duration_ms for every generation attempt. This plan exposes that data through an admin-only API endpoint and a Next.js server action for fetching it.

Output: A working admin-only debug endpoint at GET /api/debug/logs/{job_id} and a frontend server action to call it. The endpoint supports incremental polling via a `since` timestamp parameter.
</objective>

  <action>
    Create the Pydantic schema and FastAPI router for debug log entries.

    **backend/app/schemas/debug.py:**
    - Create `DebugLogEntry` Pydantic model (BaseModel with model_config ConfigDict(from_attributes=True)):
      - id: str
      - job_id: str
      - product_group_id: str
      - attempt_number: int
      - prompt_used: str (the raw prompt string containing [system] and [user] blocks)
      - model_version: str
      - temperature: float
      - input_tokens: int
      - output_tokens: int
      - cost: str (string representation of Decimal)
      - duration_ms: int
      - success: bool
      - error_message: str | None
      - generated_title: str | None
      - generated_description: str | None
      - title_length: int | None
      - description_length: int | None
      - created_at: str (ISO format datetime)

    **backend/app/routers/debug.py:**
    - Create APIRouter with prefix="/debug", tags=["debug"]
    - Endpoint: GET /logs/{job_id}
      - Parameters:
        - job_id: UUID (path)
        - since: datetime | None = Query(None) - only return logs after this timestamp (for incremental polling)
        - limit: int = Query(50, ge=1, le=200) - max entries to return
      - Auth: Depends(get_current_admin) - admin-only access
      - Query: select GenerationAudit where job_id matches, ordered by created_at ASC
      - If `since` provided, add filter: GenerationAudit.created_at > since
      - Apply limit
      - Return list of DebugLogEntry, converting UUID fields to str and Decimal cost to str, datetime to isoformat
    - Endpoint: GET /logs/client/{client_id}/latest
      - Returns audit logs for the most recent job of the given client (useful when debug panel opens mid-generation)
      - Auth: Depends(get_current_admin)
      - Query: Find the most recent GenerationJob for client_id, then return its audits
      - Parameters: since (datetime | None), limit (int, default 50)
      - If no job found, return empty list

    **backend/app/routers/__init__.py:**
    - Add: `from app.routers.debug import router as debug_router`
    - Add "debug_router" to __all__ list

    **backend/app/main.py:**
    - Add debug_router to imports from app.routers
    - Add: `app.include_router(debug_router, prefix="/api")`

    **backend/app/schemas/__init__.py:**
    - Add import: `from app.schemas.debug import DebugLogEntry`
    - Add "DebugLogEntry" to __all__ list

  <action>
    Create a Next.js server action file for debug log operations. Follow the exact pattern from `frontend/src/app/actions/export.ts`:

    **frontend/src/app/actions/debug.ts:**
    - Add 'use server' directive at top
    - Import cookies from 'next/headers'
    - Define API_URL constant (same pattern as other actions)
    - Define TypeScript interface `DebugLogEntry`:
      - id: string
      - job_id: string
      - product_group_id: string
      - attempt_number: number
      - prompt_used: string
      - model_version: string
      - temperature: number
      - input_tokens: number
      - output_tokens: number
      - cost: string
      - duration_ms: number
      - success: boolean
      - error_message: string | null
      - generated_title: string | null
      - generated_description: string | null
      - title_length: number | null
      - description_length: number | null
      - created_at: string

    - Export async function `getDebugLogs(jobId: string, since?: string): Promise<DebugLogEntry[]>`:
      - Get access_token from cookies (same pattern as export.ts)
      - If no token, return empty array
      - Build URL: `${API_URL}/api/debug/logs/${jobId}` with optional `?since=${since}` query param
      - Fetch with Authorization: Bearer ${accessToken}, cache: 'no-store'
      - If response not ok, return empty array (non-admin will get 403, silently fail)
      - Return response.json()
      - Wrap in try/catch, return empty array on error

    - Export async function `getDebugLogsForClient(clientId: string, since?: string): Promise<DebugLogEntry[]>`:
      - Same pattern but calls `/api/debug/logs/client/${clientId}/latest`
      - Returns empty array on failure

    - Export async function `getDebugToken(): Promise<string | undefined>`:
      - Same pattern as getExportToken in export.ts
      - Returns the access_token cookie value for client-side polling
  </action>
