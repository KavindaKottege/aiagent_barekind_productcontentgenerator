<task type="auto">
  <name>Task 1: Create health check router with liveness and readiness endpoints</name>
  <files>backend/app/routers/health.py</files>
  <action>
Create `backend/app/routers/health.py` with two endpoints:

**1. Liveness: GET /api/health**
- Returns `{"status": "healthy"}` with status code 200
- No dependency checks -- just confirms the process is alive and responding
- This replaces the inline health check in `main.py`

**2. Readiness: GET /api/health/ready**
- Checks both database AND Redis connectivity
- Database check: Use `async_session_maker()` to execute `SELECT 1` with a 5-second timeout using `asyncio.wait_for`
- Redis check: Use `redis.asyncio.from_url(settings.REDIS_URL)` to call `.ping()` with a 5-second timeout
- Close the Redis connection after check with `await r.aclose()`
- Collect results in a `checks` dict: `{"database": "ok", "redis": "ok"}` or `{"database": "error: ...", "redis": "ok"}`
- If ALL checks are "ok": return 200 with `{"status": "ready", "checks": {...}}`
- If ANY check fails: return 503 with `{"status": "not_ready", "checks": {...}}`
- Use `fastapi.responses.JSONResponse` for status code control

Imports needed:
- `asyncio` (for wait_for timeout)
- `fastapi.APIRouter`, `fastapi.responses.JSONResponse`
- `sqlalchemy.text` (for SELECT 1)
- `redis.asyncio as aioredis` (for Redis ping)
- `app.database.async_session_maker`
- `app.config.settings`

Create the router with `tags=["health"]`.

Wrap each dependency check in its own try/except to report individual failures. Use `str(e)` for error messages but do NOT expose stack traces.
  </action>
  <verify>
1. Start the backend API and run: `curl -s http://localhost:8000/api/health | python -m json.tool` -- should return `{"status": "healthy"}`
2. With DB and Redis running: `curl -s http://localhost:8000/api/health/ready | python -m json.tool` -- should return 200 with all checks "ok"
3. With Redis stopped: `curl -s -o /dev/null -w "%{http_code}" http://localhost:8000/api/health/ready` -- should return 503
  </verify>
  <done>Health router has both liveness and readiness endpoints that correctly report individual dependency status</done>
