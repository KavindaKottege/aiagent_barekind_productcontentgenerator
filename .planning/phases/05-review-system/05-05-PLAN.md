<task type="auto">
  <name>Task 1: Add AI review Server Actions with auto-approve support</name>
  <files>
    frontend/src/app/actions/review.ts
  </files>
  <action>
    Add AI review Server Actions to frontend/src/app/actions/review.ts:

    **Types:**
    ```typescript
    export interface AIReviewResult {
      recommendation: 'approve' | 'reject'
      reason: string
      safety_flags: string[]
      accuracy_score: number
    }

    export interface AIReviewJobStatus {
      status: string
      total_count: number
      completed_count: number
      total_cost: string
      auto_approve: boolean  // Whether in AI-auto mode
      estimated_remaining: number | null
    }
    ```

    **Server Actions:**

    1. **requestAIReview(productGroupId: string)**: Promise<AIReviewResult | null>
       - Calls POST /api/review/ai-single
       - Returns AI recommendation for single product
       - Returns null on error
       - NOTE: Single product review is always AI-assisted (recommendations only)

    2. **startBatchAIReview(clientId: string, autoApprove: boolean = false)**: Promise<{ jobId: string } | { error: string }>
       - Calls POST /api/review/{clientId}/ai-review/start with { auto_approve: autoApprove }
       - autoApprove=true: AI-auto mode (sets review_status directly)
       - autoApprove=false: AI-assisted mode (only sets ai_review_status)
       - Returns job_id for progress tracking
       - Returns error if job already running

    3. **getBatchAIReviewStatus(clientId: string)**: Promise<AIReviewJobStatus | null>
       - Calls GET /api/review/{clientId}/ai-review/status
       - Returns current job status including auto_approve flag

    4. **pauseBatchAIReview(clientId: string)**: Promise<{ success: boolean }>
       - Calls POST /api/review/{clientId}/ai-review/pause

    5. **cancelBatchAIReview(clientId: string)**: Promise<{ success: boolean }>
       - Calls POST /api/review/{clientId}/ai-review/cancel

    6. **resumeBatchAIReview(clientId: string, autoApprove: boolean = false)**: Promise<{ jobId: string } | { error: string }>
       - Calls POST /api/review/{clientId}/ai-review/resume with { auto_approve: autoApprove }
       - Can change mode on resume
  </action>
