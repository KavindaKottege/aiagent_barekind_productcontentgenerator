  </files>
  <action>
    Add AI review Server Actions to frontend/src/app/actions/review.ts:

    **Types:**
    ```typescript
    export interface AIReviewResult {
      recommendation: 'approve' | 'reject'
      reason: string
      safety_flags: string[]
      accuracy_score: number
    }

    export interface AIReviewJobStatus {
      status: string
      total_count: number
      completed_count: number
      total_cost: string
      estimated_remaining: number | null
    }
    ```

    **Server Actions:**

    1. **requestAIReview(productGroupId: string)**: Promise<AIReviewResult | null>
       - Calls POST /api/review/ai-single
       - Returns AI recommendation for single product
       - Returns null on error

    2. **startBatchAIReview(clientId: string)**: Promise<{ jobId: string } | { error: string }>
       - Calls POST /api/review/{clientId}/ai-review/start
       - Returns job_id for progress tracking
       - Returns error if job already running

    3. **getBatchAIReviewStatus(clientId: string)**: Promise<AIReviewJobStatus | null>
       - Calls GET /api/review/{clientId}/ai-review/status
       - Returns current job status

    4. **pauseBatchAIReview(clientId: string)**: Promise<{ success: boolean }>
       - Calls POST /api/review/{clientId}/ai-review/pause

    5. **cancelBatchAIReview(clientId: string)**: Promise<{ success: boolean }>
       - Calls POST /api/review/{clientId}/ai-review/cancel

    6. **resumeBatchAIReview(clientId: string)**: Promise<{ jobId: string } | { error: string }>
       - Calls POST /api/review/{clientId}/ai-review/resume
  </action>
