       - useReviewHistory for undo/redo tracking
       - useTransition for pending states during server actions

       - Shows: product_name, description, product_type, option_name, country_of_origin, made_to_order
       - Only fields that have values

       - Show ai_review_status if available with brief reason
       - Warning banner if ai_review_safety_flags not empty
