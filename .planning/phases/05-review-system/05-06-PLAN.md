    1. Create frontend/src/app/api/review/stream/route.ts:
       - Next.js API route for SSE proxy to backend
       - Connects to backend SSE for generation progress
       - Forwards events to frontend client

       ```typescript
       import { NextRequest } from 'next/server'

       export async function GET(request: NextRequest) {
         const { searchParams } = new URL(request.url)
         const clientId = searchParams.get('clientId')
         const token = searchParams.get('token')

         // Connect to backend SSE
         const backendUrl = `${process.env.NEXT_PUBLIC_API_URL}/api/generation/${clientId}/progress?token=${token}`

         const response = await fetch(backendUrl)

         // Forward SSE stream
         return new Response(response.body, {
           headers: {
             'Content-Type': 'text/event-stream',
             'Cache-Control': 'no-cache',
             'Connection': 'keep-alive',
           },
         })
       }
       ```

    2. Update frontend/src/app/(dashboard)/review/page.tsx:
       - Add state for products list
       - Check if generation is running for client
       - If generation running:
         - Show banner "Generation in progress - X products ready for review"
         - Connect to generation SSE for progress updates
         - **CRITICAL: On 'progress' event when a product completes, call getReviewProducts(clientId) to refresh the products list**
         - On 'complete' event, call getReviewProducts(clientId) to get final list
         - Debounce refresh calls (max once per 2 seconds) to avoid API spam

       - **Refresh logic:**
         ```typescript
         // Track last refresh time to debounce
         const lastRefreshRef = useRef<number>(0)
         const REFRESH_DEBOUNCE_MS = 2000

         const handleSSEProgress = (event: MessageEvent) => {
           const data = JSON.parse(event.data)
           // Update progress UI
           setProgress(data)

           // Refresh products list if enough time has passed
           const now = Date.now()
           if (now - lastRefreshRef.current > REFRESH_DEBOUNCE_MS) {
             lastRefreshRef.current = now
             getReviewProducts(clientId).then(setProducts)
           }
         }

         const handleSSEComplete = () => {
           // Always refresh on complete
           getReviewProducts(clientId).then(setProducts)
         }
         ```

       - Add "Review Available" button that navigates to first generated product
       - Update stats as new products complete
       - Show combined progress: "Generating: 45/120, Ready for review: 45"

    - On each 'progress' event, increment generated count
    - Call getReviewProducts(clientId) to refresh the product list (debounced)
    - Always call getReviewProducts(clientId) on 'complete' event
    - Keep UI responsive during long generation
