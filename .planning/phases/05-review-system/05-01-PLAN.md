  <name>Task 3: Create review API router</name>
  <files>
    backend/app/routers/review.py

  <action>
    1. Create backend/app/routers/review.py with endpoints:

    **GET /api/review/{client_id}/products**
    - Query params: status filter (all, pending, approved, rejected, ai_approved, ai_rejected, edited)
    - Returns list of ProductGroupReview ordered by row_index
    - Only returns products with status='generated' (excludes pending generation)
    - Joins first product in group to get images and original_data

    **GET /api/review/{client_id}/product/{product_group_id}**
    - Returns single ProductGroupReview for review UI
    - Includes images from first product in group
    - Includes original_data (description, product_type, option_name, country_of_origin, made_to_order)

    **POST /api/review/approve**
    - Body: ReviewActionRequest
    - Sets review_status='approved', reviewed_at=now()
    - If edited_title/description exist, they become the approved content
    - Returns next unreviewed product_group_id (row_index order) for auto-advance

    **POST /api/review/reject**
    - Body: ReviewActionRequest
    - Sets review_status='rejected', reviewed_at=now()
    - Returns next unreviewed product_group_id for auto-advance

    **POST /api/review/edit**
    - Body: EditContentRequest
    - Validates character limits (30-60 title, 2000-3000 description)
    - Sets edited_title, edited_description, review_status='edited'
    - User must explicitly approve after editing

    **POST /api/review/undo**
    - Body: { product_group_id: UUID, previous_status: str }
    - Reverts review_status to previous_status
    - Clears reviewed_at

    **GET /api/review/{client_id}/stats**
    - Returns ReviewStatsResponse with counts per status

    **GET /api/review/{client_id}/next-unreviewed**
    - Returns next product_group_id without review (review_status is null)
    - Orders by row_index for consistent queue

    2. Add router import to backend/app/routers/__init__.py
    3. Register router in backend/app/main.py with prefix="/api/review"
  </action>
