<task type="auto">
  <name>Task 1: Export server action + export dialog component</name>
  <files>
    frontend/src/app/actions/export.ts
    frontend/src/components/export-dialog.tsx
  </files>
  <action>
    1. Create `frontend/src/app/actions/export.ts`:
       - 'use server' directive
       - Import cookies from 'next/headers'
       - Define ExportStats interface: { total: number, not_generated: number, approved: number, pending: number, rejected: number }
       - `getExportStats(clientId: string)`: fetches GET /api/export/{clientId}/stats with bearer token from access_token cookie, returns ExportStats
       - `getExportToken()`: returns the access_token cookie value (string | undefined) -- this is the token passing pattern used by SSE in the review page. The client component needs this to make a direct fetch to FastAPI for the binary download.
       - Follow the same auth pattern as review.ts: read access_token cookie, include in Authorization header

    2. Create `frontend/src/components/export-dialog.tsx`:
       - 'use client' component
       - Props: `{ open: boolean, onOpenChange: (open: boolean) => void, clientId: string, clientName: string }`
       - Uses AlertDialog from '@/components/ui/alert-dialog' (already installed)
       - Uses Checkbox from '@/components/ui/checkbox'
       - Uses `toast` from 'sonner'
       - State: stats (ExportStats | null), loading (boolean), includePending (boolean, default false), downloading (boolean)
       - On open (useEffect when open=true): call getExportStats(clientId) to populate stats. Show skeleton/loading state while fetching.
       - Dialog content layout:
         * Title: "Export Products"
         * Description: "Download product data as Excel spreadsheet"
         * Stats display: show each count in a compact grid or list:
           - Total Products: {stats.total}
           - Approved: {stats.approved} (green text)
           - Pending Review: {stats.pending}
           - Rejected: {stats.rejected}
           - Not Generated: {stats.not_generated}
         * Checkbox: "Include content pending approval" with label explanation "(Updates titles/descriptions for products awaiting review)"
         * If stats.approved === 0 AND (not includePending OR stats.pending === 0): show warning "No products with updated content to export" and disable Download button. Link to /review.
         * Footer: Cancel button + Download button (with Download icon from lucide-react)
       - Download handler:
         * Set downloading=true
         * Call getExportToken() server action to get access token
         * Direct fetch to `${process.env.NEXT_PUBLIC_API_URL || 'http://localhost:8000'}/api/export/${clientId}?include_pending=${includePending}`
         * Include Authorization: `Bearer ${token}` header
         * On success: convert response to blob, create object URL, create anchor element, set download attribute to `${clientName}_products_${YYYY-MM-DD}.xlsx`, click, revoke URL, remove anchor
         * Call `toast.success('Export complete')` on success
         * Call `toast.error(errorMessage)` on failure
         * Set downloading=false, close dialog
  </action>
  <verify>

    - `frontend/src/components/export-dialog.tsx` exists with ExportDialog component
    - `cd frontend && npx tsc --noEmit` passes
  </verify>
