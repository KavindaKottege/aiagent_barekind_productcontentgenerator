    1. Create `backend/app/schemas/export.py`:
       ```python
       from pydantic import BaseModel

       class ExportStatsResponse(BaseModel):
           total: int
           not_generated: int
           approved: int
           pending: int
           rejected: int
       ```
       Add to schemas/__init__.py exports.

    2. Create `backend/app/services/excel_exporter.py` — ExcelExporter class:
       - Import openpyxl Workbook, BytesIO, ExactColumnMapper
       - Class has a `REVERSE_MAP = {v: k for k, v in ExactColumnMapper.COLUMN_MAP.items()}`
       - Method `export(products_with_groups, column_order, include_pending=False) -> BytesIO`:
         a. Create Workbook, get active sheet, set title "Products"
         b. Write header row from column_order
         c. For each product dict (ordered by row_index):
            - Determine if this product should use generated content:
              * Get group's review_status from the product dict
              * "use_generated" = review_status in ('approved', 'edited') OR (include_pending AND status == 'generated' AND review_status != 'rejected')
            - For each column header in column_order:
              * Look up field_name via REVERSE_MAP
              * If field_name == 'product_name' AND use_generated: use effective_title (edited_title if set, else generated_title, fallback to product_name)
              * If field_name == 'description' AND use_generated: use effective_description (edited_description if set, else generated_description, fallback to description)
              * If field_name and mapped: use the product's field value
              * If field_name == 'images': join list with space separator
              * If field_name == 'made_to_order': convert bool to string or leave as-is
              * If not in REVERSE_MAP: pull from unmapped_data dict
            - Append row to worksheet
         d. Save workbook to BytesIO, seek(0), return buffer
       - Add ExcelExporter to services/__init__.py exports.

    3. Create `backend/app/routers/export.py`:
       - Router with prefix="/export", tags=["export"]
       - Import: APIRouter, Depends, HTTPException, Query, StreamingResponse, select, func, UUID, date
       - Import: get_db, get_current_user, Product, ProductGroup, Client, ExcelExporter, ExportStatsResponse

       **GET /{client_id}/stats endpoint:**
       - Authenticate user, validate client ownership
       - Query ProductGroup counts for the client:
         * total = count all groups
         * approved = count where review_status IN ('approved', 'edited')
         * rejected = count where review_status == 'rejected'
         * not_generated = count where status != 'generated'
         * pending = total - approved - rejected - not_generated
       - Return ExportStatsResponse

       **GET /{client_id} endpoint:**
       - Authenticate user, validate client ownership
       - Check that client has approved products (review_status in approved/edited). If zero: raise HTTPException(400, "No approved products to export")
       - Query all Products for client_id ordered by row_index, with selectinload(Product.group) to eager-load ProductGroup
       - Build column_order: use client.excel_column_order if set, otherwise derive fallback from ExactColumnMapper.COLUMN_MAP values + union of unmapped_data keys
       - Build products_data list of dicts, each containing:
         * All mapped field values from the Product
         * unmapped_data dict
         * group info: review_status, status, generated_title, generated_description, edited_title, edited_description
       - Call ExcelExporter().export(products_data, column_order, include_pending=include_pending_query_param)
       - Return StreamingResponse with:
         * media_type = "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
         * Content-Disposition header with filename: "{client.brand_name}_products_{date.today().isoformat()}.xlsx"
       - Accept query param: include_pending: bool = Query(False)

    4. Register the export router:
       - Add to `backend/app/routers/__init__.py`: `from app.routers.export import router as export_router` and add to __all__
       - Add to `backend/app/main.py`: `app.include_router(export_router, prefix="/api")` after the regeneration router

    IMPORTANT: For the selectinload on Product.group, use `from sqlalchemy.orm import selectinload`. The Product model has a `group` relationship to ProductGroup.

    For the stats endpoint, use SQLAlchemy `func.count()` with `case()` expressions or multiple queries -- whichever is cleaner. Multiple simple queries is fine for this scale.

    For images serialization on export: if the product's images field is a list, join with " " (space). If None, use empty string.
