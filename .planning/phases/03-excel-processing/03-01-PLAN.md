Create migration 005_create_products_tables.py:
- revision = "005"
- down_revision = "004" (clients table)
- Create product_groups table first (parent in relationship)
- Create products table second (references product_groups)

product_groups table columns:
- id UUID primary key with gen_random_uuid() default
- client_id UUID FK to clients.id ON DELETE CASCADE, NOT NULL
- user_id UUID FK to users.id, NOT NULL
- product_name VARCHAR(500) NOT NULL
- product_token VARCHAR(255) NOT NULL
- sku VARCHAR(255) NOT NULL
- variant_count INTEGER NOT NULL DEFAULT 1
- generated_title VARCHAR(255) NULLABLE
- generated_description TEXT NULLABLE
- status VARCHAR(50) NOT NULL DEFAULT 'pending'
- created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT now()
- updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT now()

Indexes on product_groups:
- client_id (for listing products by client)
- (client_id, product_name, product_token, sku) UNIQUE (prevent duplicate groups per client)

products table columns:
- id UUID primary key with gen_random_uuid() default
- client_id UUID FK to clients.id ON DELETE CASCADE, NOT NULL
- user_id UUID FK to users.id, NOT NULL
- group_id UUID FK to product_groups.id ON DELETE CASCADE, NOT NULL
- product_name VARCHAR(500) NOT NULL
- product_token VARCHAR(255) NOT NULL
- sku VARCHAR(255) NOT NULL
- status VARCHAR(100) NULLABLE
- description TEXT NULLABLE
- option_name VARCHAR(255) NULLABLE
- product_type VARCHAR(255) NULLABLE
- country_of_origin VARCHAR(100) NULLABLE
- made_to_order BOOLEAN NULLABLE
- images JSONB NULLABLE (array of strings stored as JSON)
- unmapped_data JSONB NOT NULL DEFAULT '{}'
- row_index INTEGER NOT NULL
- created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT now()
- updated_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT now()

Indexes on products:
- client_id
- group_id
- (client_id, row_index) for ordering during export

Downgrade: DROP TABLE products, then DROP TABLE product_groups (order matters for FK).
