  <action>
1. Create `backend/app/routers/__init__.py` (empty)

2. Create `backend/app/utils/dependencies.py`:
   - OAuth2PasswordBearer with tokenUrl="auth/login"
   - get_current_user dependency:
     - Extract token from OAuth2PasswordBearer
     - Decode token and get user_id from "sub" claim
     - Fetch user from database
     - Raise 401 if token invalid or user not found
     - Return User object
   - get_current_admin dependency:
     - Depends on get_current_user
     - Raise 403 if user.is_admin is False
     - Return User object

3. Create `backend/app/routers/auth.py`:
   - APIRouter with prefix="/auth" and tags=["auth"]

   - POST /signup:
     - Accept UserCreate body
     - Check if email already exists (raise 400 if so)
     - Hash password using Argon2
     - Create user in database
     - First user (no other users exist) automatically becomes admin (is_admin=True)
     - Create access token
     - Return Token response
     - Log user creation (email, is_admin status)

   - POST /login:
     - Accept OAuth2PasswordRequestForm (standard form with username/password)
     - Find user by email (form.username is email)
     - Verify password
     - Raise 401 if credentials invalid
     - Create access token
     - Return Token response

   - POST /logout:
     - Depends on get_current_user
     - Return {"message": "Logged out successfully"}
     - Note: Actual token invalidation handled client-side (delete cookie)

   - GET /me:
     - Depends on get_current_user
     - Return UserResponse for current user

4. Update `backend/app/main.py`:
   - Import auth router
   - Include auth router: app.include_router(auth.router)

Use Pattern 3 from 01-RESEARCH.md. First user becomes admin per CONTEXT.md decision.
  </action>
