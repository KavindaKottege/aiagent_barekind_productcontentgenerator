  <name>Task 1: Update session.ts to store backend access_token</name>
  <files>frontend/src/lib/session.ts</files>
  <action>
Add two new functions to session.ts:

1. `setAccessToken(token: string)` - Stores the backend JWT in a separate "access_token" cookie (httpOnly, secure in prod, sameSite lax, 7 days)

2. `getAccessToken()` - Retrieves the access_token cookie value

Keep the existing encrypt/decrypt/setSession functions - they manage a separate frontend session for userId lookup (middleware still uses this). The access_token cookie holds the actual backend JWT for API calls.

This dual-cookie approach is intentional:
- "session" cookie: frontend-encrypted JWT with userId for middleware/client-side checks
- "access_token" cookie: raw backend JWT for Authorization header to backend API

Both cookies should have identical security settings (httpOnly, secure, sameSite, maxAge).

<task type="auto">
  <name>Task 3: Fix DAL to send correct Authorization header</name>
  <files>frontend/src/lib/dal.ts</files>
  <action>
Fix getUser() to send the backend JWT instead of the encrypted session cookie:

**Current bug (line 43):** Sends `Bearer ${cookie}` where cookie is the frontend-encrypted session.

**Fix:**
1. Import `getAccessToken` from "./session"
2. In getUser(), call `const accessToken = await getAccessToken();`
3. If no accessToken, redirect to /login
4. Use `Authorization: Bearer ${accessToken}` in fetch header

The verifySession() call can remain for the optimistic check (verifies frontend session exists), but the actual API call must use the backend JWT.

Updated getUser pattern:
```typescript
export const getUser = cache(async (): Promise<User> => {
  await verifySession(); // Optimistic check

  const accessToken = await getAccessToken();
  if (!accessToken) {
    redirect("/login");
  }

  const response = await fetch(`${API_URL}/auth/me`, {
    headers: {
      Authorization: `Bearer ${accessToken}`,
    },
    cache: "no-store",
  });

  if (!response.ok) {
    redirect("/login");
  }

  return response.json();
});
```
